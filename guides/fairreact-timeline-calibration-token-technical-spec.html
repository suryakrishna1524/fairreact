FairReact Timeline Calibration & Token Encryption: Technical Specification

By FairReact Protocol Architecture Group • Open Video Sync Standard v2.9 • Updated September 2026 • 11 Min Read

The FairReact protocol enables client-side, zero-install frame synchronization between two independent YouTube HTML5 player instances. This specification documents the architecture of the FairReact Token Serialization Format (v1.x), the piecewise linear timeline segmentation engine, and client-side clock drift mitigation algorithms.

1. Token Structure & Base64 Grammar

FairReact timeline calibration tokens are compact, URL-safe alphanumeric strings encoded as follows:

Token = "v1." + Base64UrlEncode( PointList ) PointList = Point *( "," Point ) Point = ReactorTimeSeconds ":" OriginalTimeSeconds

For example, a reaction video where the reactor introduces their video for 49 seconds before playing the original video from 00:00 (and later pauses at reactor timestamp 04:37 / original timestamp 03:12) is encoded as:

Raw String: "49:0,277:192" Base64 Encoded: "NDk6MCwyNzc6MTky" Full Token: "v1.NDk6MCwyNzc6MTky"

2. Piecewise Linear Timeline Segmentation

The FairReact sync engine parses the token into an ordered array of timeline segments. Each segment defines an operational state:

  • PRE_START: Reactor is introducing the video. The floating PiP window remains pre-warmed and muted; target time is clamped to original start.
  • PLAYING: Target time strictly follows \( T_{\text{orig}} = \text{seg.origStart} + (T_{\text{react}} - \text{seg.reactStart}) + \Delta_{\text{offset}} \).
  • PAUSED_ZONE: The reactor has paused the original video to deliver critical commentary. The child player auto-pauses at the exact frame.
  • ENDED: The original video has concluded. The PiP window gracefully hides.

3. Dual-Lock Clock Drift Correction Algorithm

Because web browsers schedule JavaScript execution using non-deterministic event loops, playback timing between two iframe decoders can drift by up to ±350ms over 10 minutes. FairReact deploys a continuous 100ms watchdog loop:

Drift Correction Rule: When \( | T_{\text{actual}} - T_{\text{target}} | > 0.35\text{s} \), the engine initiates an instantaneous sub-frame seek (throttled to a minimum interval of 400ms to avoid audio decoder popping). If drift is \( < 0.2\text{s} \), native playback rate micro-adjustments (\( 0.98\times / 1.02\times \)) dynamically realign the clocks with zero perceptible pitch distortion.

4. Security & Decentralized Client Execution

FairReact executes entirely within the user's browser sandbox using standard YouTube IFrame APIs. No user video data, timestamps, or personal viewing information is stored on external database servers, providing complete GDPR and CCPA privacy compliance by design.
